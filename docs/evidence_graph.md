# BUBR1-RESCUE 3.0 — Evidence Graph

## Variant-to-phenotype chain
**p.Leu737Ter** → confirmed pathogenic loss-of-function → reduced functional BUBR1.

**N1002K** → ultra-rare candidate missense variant → possible full-length but unstable/partially functional BUBR1 (**hypothesis**).

Both converge on:
**↓ functional BUBR1 → ↓ spindle assembly checkpoint → ↑ chromosome missegregation → ↑ aneuploidy**

## Rescue Route A — NAD⁺–SIRT2
Niacin / NMN / NR → support NAD⁺ → support SIRT2-dependent BUBR1 stabilization → potential ↑ functional BUBR1.

## Rescue Route B — Proteostasis
Arimoclomol → HSF1/HSP-associated proteostasis response → potential improved handling of unstable BUBR1 → potential ↑ functional BUBR1.

## Go / No-Go
**GO:** increased BUBR1 abundance **and** improved checkpoint/chromosome-segregation function.

**NO-GO:** increased protein without functional rescue, or no meaningful molecular/functional improvement.

## Critical limitations
- N1002K pathogenicity is unresolved.
- Phase is unresolved.
- No N1002K-specific rescue experiment was performed.
- Niacin and arimoclomol have not been shown to rescue N1002K.
- The ranking is a transparent project-prioritization framework, not a clinical score.
